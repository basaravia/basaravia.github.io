# Alexander Saravia — personal site

Static bilingual (Spanish/English) portfolio for `https://aisaravia.online/`.

## Deploy

The `main` branch is deployed to GitHub Pages by `.github/workflows/pages.yml`.
The custom domain is declared in `CNAME`. Configure the repository's Pages
source to **GitHub Actions** and keep the DNS records for `aisaravia.online`
pointing to GitHub Pages.

## Local preview

Open `index.html` in a browser, or run any static file server from this folder.

## Easter eggs

- Open the terminal from the hero or footer and try `help`, `coffee`, or
  `sudo make me a sandwich`.
- Enter the Konami code to reveal a small message.
